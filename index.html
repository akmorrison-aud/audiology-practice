Introduction to Audiology Practice Games

Interactive practice games built for undergraduate students in CMSD 3130 Introduction to Audiology at the University of Georgia. Each game gives feedback after every answer, so students learn from their mistakes as they go.

Audiogram Site-of-Lesion Practice

Examine air- and bone-conduction thresholds, then click the part of the ear involved: outer/middle ear, inner ear, both or none/normal hearing.

Start practicing →

Audiogram Sentence Builder

Describe each hearing loss in clinical language by placing its degree, configuration, and type into a report-style sentence.

Start practicing →

Scope of Practice Sort: Who Does What?

Sort 21 clinical responsibilities into audiologist, otolaryngologist (ENT), or both, and review the ones you missed at the end.

Start practicing →

Tympanometry Explorer

Watch the eardrum move as ear canal pressure changes and see the tympanogram draw in real time. Explore seven middle ear conditions, then test yourself with mystery ears.

Start exploring →

The games run in any modern web browser on a computer, tablet, or phone. No student data is collected; any saved progress stays in the student's own browser.
